한 줄 요약

대화 내용은 나가지 않습니다. 토큰 숫자만 내 GitHub 계정의 공개 gist에 올라가고, 순위판은 그 gist를 읽기만 합니다.

무엇이 공개되나

node collect.mjs --publish(또는 맥 앱)는 내 계정에 공개 gist 하나를 만들고, 그 안의 token-meter.json 파일에 아래 칸만 담습니다. 올리기 전에 매번 이 목록 밖의 칸을 걸러 내고, 256KB가 넘으면 올리지 않습니다.

  • loginGitHub 아이디
  • updatedAt올린 시각
  • schema, app파일 형식 표시(1, token-meter)

도구(Claude Code · Codex · Gemini CLI)마다 한 묶음씩:

  • tool도구 이름
  • generatedAt수집한 시각
  • tz컴퓨터의 시간대 이름(예: Asia/Seoul)
  • range첫 활동일 · 마지막 활동일 · 활동한 날 수
  • totals입력 · 출력 · 캐시 쓰기 · 캐시 읽기 · 총 토큰 · API 환산 금액 · 응답 수
  • messages, sessions, subagents응답 · 세션 · 서브에이전트 개수
  • split메인 대화와 서브에이전트가 쓴 토큰
  • byModel모델 이름별로 위와 같은 숫자
  • byDay날짜별 [총 토큰, 출력 토큰, API 환산]
  • estimated단가표에 없는 모델이 섞였는지(예/아니오)

숫자뿐이지만 알 수 있는 것도 있습니다: 어느 날 일했는지(날짜별 기록), 대략 어느 지역인지(시간대 이름), 어떤 모델을 쓰는지(모델 이름). 도구에 직접 설정한 모델 이름(예: Codex 사용자 지정 모델, 회사 안에서 붙인 배포 이름)도 그대로 공개되니, 숨기고 싶은 이름이라면 참가 전에 확인하세요.

공개되지 않는 것

  • 대화 내용 · 프롬프트 · 답변 · 코드 (수집기가 내 컴퓨터의 세션 로그를 읽기는 하지만, 거기서 토큰 숫자·모델 이름·날짜만 골라 내고 내용은 어디에도 보내지 않습니다)
  • 파일 경로 · 작업 폴더 · 프로젝트 이름과 개수
  • 세션 id · 컴퓨터 사용자 이름 · 닉네임
  • 그 밖의 진단 정보

gist 수정 기록은 계속 공개로 남습니다

GitHub gist는 고칠 때마다 이전 판(revision)을 남기고, 누구나 볼 수 있습니다. 수집기가 다시 올릴 때마다 판이 하나씩 쌓입니다. 판 하나만 지울 수는 없고, gist를 통째로 지워야 사라집니다. 지우기 전에 누가 복사해 둔 것까지는 막을 수 없습니다.

참가 명단(members.json)은 이 저장소에 커밋됩니다. 명단에서 빠져도 저장소 기록에는 GitHub 아이디와 gist id가 남고, 참가·탈퇴 이슈도 공개입니다.

그만두는 법

  1. 탈퇴 이슈 열기 — 탈퇴 신청서를 제출하면 자동으로 명단에서 빠집니다.
  2. gist 지우기 — gist.github.com에서 token-meter gist를 열어 Delete, 또는 터미널에서 gh gist delete <gist id>.
  3. 다시 올라가지 않게 — 맥 앱을 쓴다면 아래의 ‘올리기’ 체크를 풀거나 앱을 끄세요(고른 간격 — 10분~6시간 — 마다, 숫자가 바뀌었을 때만 올립니다). 수집기가 기억해 둔 gist id는 ~/.token-meter/gist.json에 있습니다 — 지워도 됩니다.

이 사이트와 아이폰 앱(준비 중)은 아무것도 수집하지 않습니다

서버가 없습니다. 쿠키·분석 도구·로그인·계정도 없습니다. 브라우저에 저장하는 건 언어 선택 하나뿐입니다. 순위판은 명단과 각자의 gist를 읽기만 하고, 아이폰 앱(준비 중)도 마찬가지입니다.

다만 페이지를 열면 브라우저가 GitHub(이 페이지 · 명단 · gist · 프로필 사진)와 Google Fonts(글꼴)에서 파일을 받아 오므로, 두 회사는 보통의 접속 기록(IP 주소 등)을 볼 수 있습니다. 이건 각 회사의 개인정보 처리방침을 따릅니다.

Privacy, in English

Your conversations never leave your machine. Only token numbers go to a public gist in your own GitHub account, and the leaderboard only reads that gist.

What is published

node collect.mjs --publish (or the Mac app) creates one public gist in your account with a single file, token-meter.json, holding only the fields below. Everything else is filtered out before every upload, and nothing over 256 KB is uploaded.

  • loginyour GitHub login
  • updatedAtwhen it was uploaded
  • schema, appformat markers (1, token-meter)

One block per tool (Claude Code · Codex · Gemini CLI):

  • tooltool name
  • generatedAtwhen it was collected
  • tzyour computer's time zone name (e.g. Asia/Seoul)
  • rangefirst and last active day, number of active days
  • totalsinput · output · cache write · cache read · total tokens · API-equivalent cost · responses
  • messages, sessions, subagentscounts of responses, sessions and subagents
  • splittokens used by the main conversation vs subagents
  • byModelthe same numbers per model name
  • byDayper date: [total tokens, output tokens, API-equivalent]
  • estimatedwhether a model missing from the price table was involved (yes/no)

Numbers still say something: which days you worked (daily records), roughly where you are (time zone name) and which models you use (model names). A model name you configured yourself (for example a custom Codex model or an internal deployment name at work) is published as is, so check it before joining if it should stay private.

What is never published

  • conversations, prompts, replies, code (the collector reads your local session logs, but keeps only token counts, model names and dates, and sends no content anywhere)
  • file paths, working folders, project names or project counts
  • session ids, your computer user name, nicknames
  • any other diagnostics

Gist revisions stay public

A GitHub gist keeps every earlier revision, and anyone can read them. Each re-upload adds one. You cannot delete a single revision — only the whole gist — and nothing can undo a copy someone made before you deleted it.

The member list (members.json) is committed to this repository. Leaving removes you from the list, but your login and gist id stay in the repository history, and join/leave issues are public too.

How to leave

  1. Open a leave issue — submit the leave form and you are removed from the list automatically.
  2. Delete the gist — open your token-meter gist on gist.github.com and choose Delete, or run gh gist delete <gist id>.
  3. Stop re-uploading — if you use the Mac app, untick “올리기” (upload) or quit it (it uploads at the interval you chose — 10 minutes to 6 hours — and only when the numbers changed). The collector remembers your gist id in ~/.token-meter/gist.json; you can delete that file.

This site and the iPhone app (coming) collect nothing

There is no server, and no cookies, analytics, sign-in or accounts. The only thing stored in your browser is your language choice. The leaderboard only reads the member list and each gist, and so will the iPhone app (coming).

Opening the page does make your browser download files from GitHub (this page, the member list, the gists, profile pictures) and Google Fonts (typefaces), so those two companies see ordinary request data such as your IP address, under their own privacy policies.
